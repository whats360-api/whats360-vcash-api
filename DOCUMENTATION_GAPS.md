# Documentation gaps (VCash)
- Error body and status codes: not shown on the dashboard page.
- USSD: only `status: pending` is shown. How to read the final result is not documented here.
- `sim_slot`: example uses 1. Other values not documented.
- Rate limits and plan requirements: not documented.
- Phone number format: the sample uses a local Egyptian format (11 digits). International format is not documented for this endpoint.
- Never publish a real token, device id or phone number in an issue.
